# ML Data

- `demo_loan_data.csv` - synthetic training dataset (6,000 rows, seed 42),
  generated by `../scripts/generate_demo_data.py`. Synthetic data for
  academic demonstration only.
- `processed/seed_applications.json` - realistic demo application
  records (scored by the real trained model), generated by
  `../scripts/seed_demo_applications.py`, consumed by
  `backend/scripts/seed_mongodb.py`.
